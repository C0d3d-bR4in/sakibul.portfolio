# Sakibul Islam Sheikh | Portfolio

A modern, responsive personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS. This project showcases my work, experience, and contact information in a polished single-page experience.

## ✨ Features

- Responsive and visually appealing portfolio layout
- Smooth scroll-based reveal animations
- Sections for About, Experience, Projects, and Contact
- Interactive contact form powered by EmailJS
- Clean UI built with shadcn/ui and Tailwind CSS

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- EmailJS
- Lucide Icons and React Icons

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js 18+
- npm or bun

### Installation

```bash
git clone https://github.com/C0d3d-bR4in/your-repo-name.git
cd your-repo-name
npm install
```

### Development

```bash
npm run dev
```

The app will be available in your browser at the local Vite URL.

### Build

```bash
npm run build
```

### Test

```bash
npm run test
```

## 📁 Project Structure

```bash
src/
  components/     # Page sections and reusable UI
  hooks/          # Custom hooks
  lib/            # Utility helpers
  pages/          # Main app pages
```
